# Architecture

## Overview

The Food Audit Agent follows a modular architecture with clear separation of concerns:

- **Core**: Agent orchestration, checkpoint registry, workflow engine, data models
- **Knowledge**: Structured audit checkpoint definitions (markdown-based)
- **Skills**: Reusable AI capabilities (document analysis, image analysis, etc.)
- **Workflows**: Audit flow definitions that sequence checkpoints
- **Prompts**: LLM prompt templates for various audit tasks
- **Reports**: Audit report generation and storage
