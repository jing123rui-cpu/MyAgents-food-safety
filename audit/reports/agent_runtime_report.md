## Public API

### `initialize() -> Dict[str, Any]`

Loads all knowledge and initialises all subsystems.

**Returns** startup summary with counts and overall status.

## Example Usage

```python
from core import FoodAuditAgent
from core.models import Evidence, EvidenceType

# Startup
agent = FoodAuditAgent("knowledge")
summary = agent.initialize()
print(summary["status"])  # READY

# Inspect by keyword
ctx = agent.inspect(query="supplier")
print(len(ctx.matched_checkpoints))  # 5

# Inspect with evidence
evidence = [
    Evidence(
        id="EVID-001",
        evidence_type=EvidenceType.PHOTO,
        checkpoint_id="CP-BEV-RM-001",
        description="渚涘簲鍟嗚鍙瘉鐓х墖",
        attachments=["photos/license.jpg"],
    )
]
ctx = agent.inspect(checkpoint_id="CP-BEV-RM-001", evidence=evidence)
print(ctx.evaluation_results[0].status)  # PASS

# Health check
status = agent.health()
```
