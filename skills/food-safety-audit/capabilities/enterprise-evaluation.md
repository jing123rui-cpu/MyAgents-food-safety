# 企业评价（enterprise_evaluation）

**状态**：已实现 · **阶段**：4 - 企业级结论

## 用途

把逐条检查点结果汇总成企业级结论：通过 / 需整改，并给出计数摘要。

## 引擎实现

`audit/script/models.py` 中的 `EnterpriseEvaluation` 数据类。

判定逻辑：

```
不符合项数 == 0  → overall_result = "企业通过检查"
不符合项数  > 0  → overall_result = "企业需要整改"
```

## 输入 / 输出

- 输入：`evaluation_results`（全部检查点结果）
- 输出：`EnterpriseEvaluation` —— 检查点总数、符合数、不符合数、不适用数、总体结论、中文摘要

## 在对话中的用法

1. 先确保每条证据都有判定结果（见 [风险评估](risk-assessment.md)）。
2. 汇总时区分三类计数，**不适用项不计入分母**，否则会虚增符合率。
3. 结论表述用「本次检查发现 X 项不符合，其中重大 Y 项」，避免只写「通过/不通过」。
4. 需要分级结论时，用 `references/risk-grading.md` 补充风险画像，不要改动引擎的二元结论口径。

## 局限

- 结论是二元的（通过 / 需整改），没有「有条件通过」这类中间态。
- 不按严重程度加权：1 项轻微不符合与 1 项重大不符合，结论相同。**因此对外表述必须同时给出风险等级分布**，不能只引用总体结论。
- 不替代监管部门的行政认定。
