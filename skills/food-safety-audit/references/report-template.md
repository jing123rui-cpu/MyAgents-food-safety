## 写作要求

1. **事实与判断分离**：第四节写事实，第五、六节写判断和建议。
2. **五要素齐全**：谁、何时、何地、什么行为或状态、什么证据。
3. **可核查**：每条事实都能对应照片编号、记录页码或访谈对象。
4. **可执行**：整改要求写到「谁在什么时间前完成什么，用什么证据验证」。
5. **不越权**：不写行政处罚决定，不写「建议吊销许可证」这类结论性处置；如需，写「建议依法进一步调查处理」。
6. **术语一致**：全文统一用「不符合项」，不用「问题点/缺陷/隐患」混用。
7. **风险等级**与 `references/risk-grading.md` 保持一致。

## 常见退回原因（自查）

- [ ] 不符合项只有结论没有事实
- [ ] 引用条款号错误或引用了已废止标准
- [ ] 风险等级与事实不匹配
- [ ] 整改要求无时限、无验证方式
- [ ] 报告里出现企业未确认的推断
- [ ] 照片编号与正文不对应
