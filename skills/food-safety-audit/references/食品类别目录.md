# 食品类别目录

## 当前支持的类别

定义于 `models.py` 的 `FOOD_CATEGORIES`：

| 类别名称 | 对应目录 | 说明 |
|---------|---------|------|
| 食用油 | `食品安全管理合规技术服务学习文件/2.食用油/` | 含植物油、油脂制品、动物油脂 |
| 饮料 | `食品安全管理合规技术服务学习文件/3.饮料/` | 含包装饮用水、碳酸饮料、果蔬汁、蛋白饮料等 |
| 方便食品 | `食品安全管理合规技术服务学习文件/4.方便食品/` | 含方便面、方便米饭、方便菜肴等 |
| 特殊膳食 | `食品安全管理合规技术服务学习文件/5.特殊膳食/` | 含婴配食品、特医食品、运动营养食品等 |

## 添加新类别

如需新增食品类别，需修改 `knowledge_base.py` 中的以下4处：

1. `CATEGORY_DIR_MAP` — 添加类别与学习文件目录的映射
2. `CATEGORY_FILES_INFO` — 添加专项法规标准清单
3. `get_category_key_points()` — 添加工艺风险要点
4. `get_category_risk_alerts()` — 添加舆情风险提示

同时需在 `models.py` 的 `FOOD_CATEGORIES` 中添加枚举值，并在 `食品安全管理合规技术服务学习文件/` 下创建对应目录。
