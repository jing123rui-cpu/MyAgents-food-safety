# 食品生产企业检查前风险分析与要点生成

## 定位

在**现场检查前**，根据企业信息、食品类别、生产工艺、法规标准与历史风险信息，识别潜在高风险环节、确定检查关注重点、推荐优先检查区域、提示重点核查资料、提供风险研判依据。

输出的是**检查前分析清单**，不是检查结论，也不是检查报告。

## 禁止输出

- 企业是否合格的结论
- 行政处罚建议
- 检查报告
- 整改通知书

## 输入

| 输入项 | 说明 | 是否必需 |
|---|---|---|
| 企业名称 | 用于资质与属地关联 | 必需 |
| 食品类别 | 食用油 / 饮料 / 方便食品 / 特殊膳食 等 | 必需 |
| 许可证信息 | 编号、许可范围、有效期 | 建议 |
| 生产工艺 | 主要工序、关键控制点 | 建议 |
| 企业规模 | 大型 / 中型 / 小型 / 微型 | 建议 |
| 历史检查与舆情 | 前次问题、抽检不合格、投诉举报 | 可选 |

## 流程（6 步，顺序执行）

```
01-企业基本信息分析
      ↓
02-食品类别识别
      ↓
03-生产工艺风险分析
      ↓
04-法规标准匹配
      ↓
05-历史风险信息分析
      ↓
06-检查重点生成
```

每一步的输出是下一步的输入；第 6 步汇总为检查前分析清单。

| 步骤 | 文件 | 核心产出 |
|---|---|---|
| 01 | `workflows/01-企业基本信息分析.md` | 资质状态、规模倾向、属地信息 |
| 02 | `workflows/02-食品类别识别.md` | 类别判定、许可范围一致性、对应法规目录 |
| 03 | `workflows/03-生产工艺风险分析.md` | 高风险工序、关键控制点、易失控环节 |
| 04 | `workflows/04-法规标准匹配.md` | 适用法规清单、重点条款 |
| 05 | `workflows/05-历史风险信息分析.md` | 历史问题聚类、复发风险 |
| 06 | `workflows/06-检查重点生成.md` | 14 项要点关注等级 + 证据清单 |

## 判断原则

1. **类别固有风险优先**：特殊膳食 > 饮料（蛋白/果蔬汁）> 方便食品 > 食用油，但需结合工艺修正。
2. **历史问题加权**：同类问题二次出现，关注等级至少上调一级。
3. **规模修正**：小型/微型企业在人员管理、自查制度、记录追溯上默认加强关注。
4. **证据导向**：每条关注点必须落到「查什么资料/看什么现场」，不写无法验证的空话。
