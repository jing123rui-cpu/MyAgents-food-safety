# 食品安全风险评估方法

> **维护边界**：跨域通用的风险评估方法（四步法、暴露与表征、概率评估、排序、不确定性）与可执行脚本以**公共技能 `risk-assessment`**（`公共技能/skills/risk-assessment/`）为准；本文件保留 GB/CFSA 域内细化、算例与食品安全场景约定。两者冲突时，方法以公共技能为准，限量与法规以本专家私有库与现行 GB 为准。

> 整理范围：化学性危害（农兽药残留、重金属、真菌毒素、加工污染物、食品添加剂等）与微生物性危害的风险评估通用方法。
> 主要依据：国家食品安全风险评估中心（CFSA）技术文件、WHO/FAO 环境健康基准系列 EHC 240、WHO/JECFA/JMPR、EFSA、FAO/WHO 食品法典（Codex）及 US EPA 风险评价指南。
> 说明：文中示例数据均为**假设值**，仅用于演示演算，不代表任何真实食品的限量或监测结果；实际评估须以权威数据库与实测数据为准，不确定处已标注“待核实”。

## 一、风险评估四步法框架

### 1.1 定义

食品安全风险评估，指对食品、食品添加剂中**生物性、化学性和物理性危害**对人体健康可能造成的不良影响所进行的科学评估，包括**危害识别、危害特征描述、暴露评估、风险特征描述**等（《食品安全风险评估管理规定（试行）》）。

风险评估是**风险分析**框架的三大支柱之一，与**风险管理**（制定标准、控制措施）和**风险交流**（信息沟通）相互独立又相互衔接。风险评估应遵循**科学、透明、个案处理**原则，评估机构独立开展工作。

### 1.2 四个步骤

| 步骤 | 英文 | 核心任务 | 主要数据/方法 | 产出 |
|---|---|---|---|---|
| 危害识别 | Hazard identification | 确定危害因素是否可能对健康造成不良影响，及可能受累人群 | 流行病学、动物试验、体外试验、结构-活性关系、文献 | 危害清单与定性判断 |
| 危害特征描述 | Hazard characterization | 对不良健康作用作定性/定量描述，确定剂量-反应关系与健康指导值 | 毒理学试验、剂量-反应建模、BMD/NOAEL、UF | 健康指导值（ADI/TDI/ARfD 等）或剂量-反应关系 |
| 暴露评估 | Exposure assessment | 估算不同人群经膳食（及其他途径）摄入危害的水平 | 食品中浓度 × 消费量 ÷ 体重；点评估/概率评估 | EDI/ESTI/IESTI 或暴露分布 |
| 风险特征描述 | Risk characterization | 综合前三步，判断风险及其程度，描述不确定性 | HQ、MOE、ILCR、人群概率 | 分级结论与不确定性说明 |

### 1.3 数据来源优先级（CFSA 技术指南）

1. 优先采用**国内**监测/调查数据（消费量、污染水平、添加剂含量）与权威技术报告。
2. 国际权威机构结论可直接引用：WHO、FAO/WHO 食品添加剂联合专家委员会（JECFA）、FAO/WHO 微生物风险评估联席会议（JEMRA）、FDA、US EPA、EFSA。
3. 资料不足时，可依据国际指南或我国标准开展毒理学评价，或使用 QSAR、毒理学关注阈值（TTC）等计算毒理学工具。
4. 特殊情况下可用 GEMS/Food 区域膳食数据或替代数据，但须说明理由。

### 1.4 方法选择：确定性 vs 概率性

| 特征 | 确定性（点）评估 | 概率性（随机）评估 |
|---|---|---|
| 输入 | 单点值（均值、中位数、P95、最大值） | 完整分布（个体数据） |
| 输出 | 单一暴露值/HQ | 暴露分布与超标概率 |
| 复杂度 | 低、快速 | 高、需软件 |
| 适用 | 筛查、初筛、应急 | 精细评估、决策支持 |
| 原则 | 避繁就简，按数据可及性与目的选择 | 能提供更多风险管理信息 |

## 二、剂量-反应评估

### 2.1 关键剂量与分离点（POD）

**分离点（Point of Departure, POD）**是推导健康指导值的起点剂量，取决于测试系统、观察终点、剂量设计与毒作用模式。

| 术语 | 全称 | 定义要点 |
|---|---|---|
| NOAEL | 未观察到不良作用剂量（No-Observed-Adverse-Effect Level） | 以现有技术和检测指标未观察到任何与受试物有关有害作用的**最大剂量**；适用于无遗传毒性物质 |
| LOAEL | 观察到不良作用最低剂量（Lowest-Observed-Adverse-Effect Level） | 引起组织形态、功能、生长发育等有害效应的**最小剂量**；仅在无法获得 NOAEL/BMDL 时使用，需加额外 UF |
| BMD | 基准剂量（Benchmark Dose） | 由剂量-反应模型求得的、引起特定反应改变或较低健康风险发生率（计量资料常取 5%，计数资料常取 10%）的剂量 |
| BMDL | 基准剂量下限（Benchmark Dose Lower confidence limit） | BMD 的 95% 可信限下限（默认单侧），用作 POD |

**NOAEL 的局限**：依赖于试验剂量设计（NOAEL 必为某试验剂量）、受样本量影响、实验变异会抬高 NOAEL；因此现代评估**优先使用 BMD 法**（JECFA/JMPR 已将 BMD 作为首选）。

**BMD 建模四步**（据 CFSA《食品中化学物健康指导值制定指南》与 WHO EHC 240）：

```
第一步：明确数据类型，确定基准反应水平 BMR
        计量资料默认 BMR = 5%；动物计数资料常用 1%/5%/10%（10% 较常用）；
        人群计数资料样本量大时常用 1%
第二步：选择备选剂量-反应模型（常用 BMDS、PROAST 软件）
第三步：拟合最佳模型
        - 似然比检验：增加参数是否显著改善拟合（对数似然差 > 1.92 对应 P<0.05）
        - 与全模型比较，无显著差异者可选
第四步：估计 BMD 与 BMDL，选最低 BMDL 作为该化学物 POD
        若同一试验各终点 BMDL 间相差超过一个数量级，需调整 BMR/模型/重新评估
```

BMD 法适用情形：① NOAEL 无法确定；② 遗传毒性与致癌物；③ 流行病学资料剂量-反应评估。

### 2.2 健康指导值（HBGV）

| 类型 | 名称 | 适用 | 说明 |
|---|---|---|---|
| ADI | 每日允许摄入量 | 食品添加剂、农药残留、兽药残留等**有意添加/使用**的化学物 | 终生每日经食物或饮水摄入，不产生可检测健康危害的量 |
| TDI | 每日可耐受摄入量 | 无蓄积作用的**不可避免**化学物 | 环境污染物、加工产物、迁移物等 |
| PMTDI | 暂定每日最大耐受摄入量 | 有蓄积作用物质 | “暂定/maximum”现多主张不再使用 |
| PTWI | 暂定每周可耐受摄入量 | 有蓄积作用物质 | 时间单位取最适宜于半衰期者 |
| PTMI | 暂定每月可耐受摄入量 | 蓄积作用强、半衰期长者 | 如 JECFA 对镉的评估 |
| ARfD | 急性参考剂量 | 急性毒性物质（如某些农药） | 24 小时或更短时间内摄入不产生可检测健康危害的量 |

特殊类型：**暂定 ADI（temporary ADI）**、**类别 ADI（group ADI）**、**不作具体规定的 ADI（ADI not specified）**、**不能提出 ADI（no ADI allocated）**。

### 2.3 不确定系数（UF）

**默认 100 倍法**（动物资料外推到人）：

```
UF_overall = UF_种间 × UF_种内 = 10 × 10 = 100
  种间（动物→人）10：毒代动力学 4 × 毒效动力学 2.5
  种内（人群个体差异）10：毒代动力学 3.16 × 毒效动力学 3.16
```

| 情形 | UF 处理 |
|---|---|
| POD 来自人体研究（无需种间外推） | 不使用种间 10 倍；可考虑默认 10 倍 |
| 已做异速生长（allometric）剂量校正 | 种间剩余不确定用 2.5 倍 |
| 以 LOAEL 代替 NOAEL | 额外增加 UF（通常 2~10，默认可设 10） |
| 亚慢性外推慢性、数据缺失、数据库不完整、数据质量差 | 额外增加 UF（通常 2~10） |
| 有充分毒代/毒效数据 | 可用**化学物特异性调整系数（CSAF）**替代默认子系数 |

### 2.4 推导公式

```
健康指导值 HBGV = 分离点 POD / 不确定系数 UFs

例（假设）：POD(BMDL) = 5 mg/kg bw/d，UF = 100
            ADI = 5 / 100 = 0.05 mg/kg bw/d
```

> 注意：以上 UF 数值为国际通行默认值（EHC 240 / CFSA 指南）；具体物质是否增减、增减多少属专家判断，应在报告中说明。

## 三、暴露评估

### 3.1 基本公式

```
膳食暴露量 = Σ (食品中危害因素浓度 × 食品消费量) / 体重

其中：
  浓度   单位 mg/kg（或 µg/kg）
  消费量 单位 kg/人·d（急性评估可用 kg/餐或 kg/d）
  体重   单位 kg（个体或人群平均）
  暴露量 单位 mg/kg bw/d（或 µg/kg bw/d）
```

CFSA 技术指南明确：膳食暴露量原则上应为某个体（或人群）通过**所有相关食物**摄入目标危害因素的总和，通常以每公斤体重表示。

### 3.2 EDI / ESTI 等常用指标

| 缩写 | 名称 | 含义 |
|---|---|---|
| EDI | 估计每日摄入量（Estimated Daily Intake） | 慢性/一般暴露，常与 ADI/TDI 比较 |
| ESTI | 估计短期摄入量（Estimated Short-Term Intake） | 急性暴露估计 |
| IEDI | 国际估计每日摄入量 | JMPR 用于农药残留慢性评估 |
| NEDI | 国家估计每日摄入量 | 各国自评慢性暴露 |
| IESTI | 国际估计短期摄入量 | JMPR 农药残留急性评估 |
| NESTI | 国家估计短期摄入量 | 各国自评急性暴露 |
| GEADE | 全球急性暴露估计 | 兽药残留等急性评估 |
| GECDE | 全球慢性暴露估计 | 慢性模型膳食 |

### 3.3 急性与慢性暴露

| 维度 | 急性（短期，<24 h） | 慢性（终生） |
|---|---|---|
| 比较对象 | ARfD | ADI/TDI/PTWI 等 |
| 浓度取值 | 高端值或最大值（HR/STMR、P95、最大残留） | 均值、中位数、P95 组合 |
| 消费量取值 | 大份餐（P97.5，单日不平均） | 多日调查平均，调整个体内变异得“通常摄入” |
| 关注人群 | 高消费个体 | 一般人群、敏感亚人群 |
| 典型方法 | IESTI（分情形） | 点评估、概率评估、模型膳食 |

### 3.4 IESTI 大份餐法（JMPR 农药残留急性暴露）

**核心思想**：对每种食品**单独**计算，假设个体不会在同一餐/24 h 内同时吃两种均含最高残留的大份餐；大份餐取消费量 **P97.5**（单消费者日，不做多日平均）；国际评估优先用各国调查的**平均体重**。

四种情形（据 WHO EHC 240）：

| 情形 | 条件 | 公式 |
|---|---|---|
| Case 1 | 单位重 < 0.025 kg（如豌豆、葡萄），或动物产品/谷物等 | `IESTI = (LP × HR) / bw` |
| Case 2a | 单位重 ≥ 0.025 kg 且 < LP（如苹果） | `IESTI = [U × HR × vf + (LP − U) × HR] / bw` |
| Case 2b | 单位重 ≥ LP（如西瓜） | `IESTI = (U × HR × vf) / bw` |
| Case 3 | 加工/混合产品（奶、面粉、油、果汁） | `IESTI = (LP × STMR) / bw` |

符号：`LP` 大份餐（97.5 百分位消费量）；`HR` 最高残留；`STMR` 规范试验中位残留；`U` 单位重量；`vf` 变异系数（default **3**，JMPR 自 2003 年起采用）；`bw` 体重。

### 3.5 消费量数据来源

- **国内**：国家食品安全风险评估中心食物消费量调查、中国居民膳食调查、总膳食研究。
- **国际**：WHO **GEMS/Food** 数据库（大份餐 P97.5、单位重量、cluster diets）；FAO **GIFT** 平台；EFSA 食物消费数据库及 DietEx 工具。
- 消费量数据类型：24 h 回顾、膳食记录、食物频率问卷（FFQ）、食物习惯问卷；个体记录 vs 汇总数据。

### 3.6 点评估与概率评估比较

| 对比项 | 点（确定性）评估 | 概率（Monte Carlo）评估 |
|---|---|---|
| 输入 | 各参数单点统计值 | 参数概率分布 |
| 组合方式 | 直接代入公式 | 随机抽样组合，重复 N 次 |
| 输出 | 单一值 | 暴露分布、P95/P99、超标概率 |
| 偏差 | 高端值组合易高估；均值组合可能低估 | 更接近真实人群分布 |
| 敏感性 | 无法量化 | 可做敏感性/贡献分析 |
| 数据要求 | 低 | 高（需分布信息） |

### 3.7 统计值选择速查（CFSA 技术指南）

| 评估类型 | 浓度取值 | 消费量取值 |
|---|---|---|
| 急性（短期） | 高端值（P95/P97.5）或最大值 | 高端值（P97.5）或最大值 |
| 慢性（长期） | 均值、中位数、P95 等组合 | 均值、中位数、P95 等组合 |
| 营养素 | 同时关注 P25 等低端值 | — |

## 四、风险表征

### 4.1 有阈值物质：危害商 HQ（Hazard Quotient）

```
HQ = 暴露量 / 健康指导值 = EDI / ADI（或 TDI、PTWI 换算后）
%ADI = HQ × 100%

判据：
  HQ ≤ 1      → 暴露量未超过健康指导值，一般视为可接受
  HQ > 1      → 超过健康指导值，需关注，宜结合毒性、暴露时长/频率综合评价
```

若为多个食品合计暴露，应使用总暴露量与 HBGV 比较；对同类毒性物质应做**累积暴露**（类别 ADI）评估。

### 4.2 无阈值物质：暴露边界 MOE（Margin of Exposure）

适用于无法制定 HBGV 的物质，如遗传毒性致癌物、数据不足的污染物。

```
MOE = 分离点 POD / 暴露量 = BMDL / 暴露量
（致癌物常用 BMDL10，即 10% 肿瘤发生率的基准剂量下限）

判据（国际常用惯例）：
  MOE ≥ 10 000  → 一般视为低健康关注
  MOE < 10 000  → 需关注，应结合不确定性、暴露性质综合判断
```

> WHO EHC 240 指出：MOE 无单一严格判据，解读时须考虑暴露不确定性、种间外推与人群变异、研究质量、致癌过程等。上述 10 000 为 EFSA/JECFA 等的常用参照，具体评估应注明依据。

### 4.3 致癌风险：终生致癌风险增量 ILCR

对有致癌斜率因子的物质，可在特定管理场景估算（非食品安全评估的通用首选）：

```
ILCR = CDI × SF
  CDI = 慢性日暴露量（mg/kg bw/d）
  SF  = 经口致癌斜率因子（(mg/kg bw/d)^-1）
判据（参考 US EPA）：
  ILCR ≤ 10^-6          → 通常视为可接受水平
  10^-6 < ILCR ≤ 10^-4  → 处于关注区间，需评估与管理
  ILCR > 10^-4          → 风险较高，通常需采取控制措施
```

### 4.4 风险分级

| 等级 | 定量特征 | 定性表述 | 处置建议 |
|---|---|---|---|
| 可接受 | HQ ≤ 1 且 MOE 充足；ILCR ≤ 10^-6 | 低 | 常规监测 |
| 需关注 | HQ 略 > 1 或 MOE < 10 000；ILCR 10^-6~10^-4 | 中 | 加强监测、评估暴露来源、风险交流 |
| 超限/高风险 | HQ 显著 > 1；MOE 远低于阈值；ILCR > 10^-4 | 高 | 风险管理措施、溯源、下架/召回、消费提示 |

风险特征描述应分别面向**个体**（高风险个体 + 多数个体平均风险）与**人群**（总人群、亚人群、特殊人群），并充分描述不确定性。

## 五、风险排序

目的：在资源有限时确定优先治理的“危害—食品”组合。

### 5.1 矩阵法（可能性 × 严重度）

| 可能性 \ 严重度 | 低 | 中 | 高 |
|---|---|---|---|
| 高 | 中 | 高 | 极高 |
| 中 | 低 | 中 | 高 |
| 低 | 低 | 低 | 中 |

- **可能性（概率）**可依据：检出率、超标率、暴露量是否超 HBGV、发生频次。
- **严重度**可依据：健康效应性质（致癌/急性中毒/慢性）、受累人群规模、可逆性、是否敏感人群。

### 5.2 赋分法（综合风险指数）

常用“多维加权”思路，把风险量化为可比较的分值：

```
风险指数 R = 检出率权重 × 超标率权重 × 消费量权重 × 健康效应权重
（各因素先归一化到 0~1 或分级赋分，再按权重求和/乘积）

亦可写成：
S = Σ (Wi × Si)
  Wi 为第 i 个指标权重（ΣWi = 1）
  Si 为第 i 个指标标准化得分
```

常用指标：**检出率、超标率、消费量/暴露量、健康效应严重度、暴露人群规模、可控制性、公众关注度**。健康效应权重应参考毒理学证据强度（如 IARC 分类、遗传毒性）。

> 赋分法无统一标准公式，权重与分值需通过专家咨询或层次分析（AHP）确定并说明，避免主观随意。

### 5.3 多准则决策分析（MCDA）

- **层次分析法（AHP）**：构建“目标—指标—方案”层次，成对比较确定权重，一致性检验。
- **TOPSIS**：计算各方案与正/负理想解的距离，贴近度排序。
- **风险矩阵 + 排序表**：将评分转为极/高/中/低等级，形成优先治理清单。

## 六、不确定性与敏感性分析

### 6.1 不确定性来源（CFSA 技术指南）

| 来源 | 示例 |
|---|---|
| 数据 | 样本量不足、检出限以下处理、代表性不足、数据缺失 |
| 模型 | 剂量-反应模型选择、外推模型 |
| 情形假设 | 消费量假设、加工因子、默认体重 |
| 科学认知 | 作用机制不明、多种化学物联合毒性 |

原则上应充分描述不确定性及其对结果的影响，并在报告中列出假设与局限。

### 6.2 概率评估（Monte Carlo）

```
1. 为每个输入参数指定概率分布（如浓度取对数正态/经验分布，
   消费量取经验分布，体重取正态/对数正态）
2. 从各分布独立随机抽样，代入暴露公式得到一次暴露值
3. 重复 N 次（通常 ≥10 000），得到暴露分布
4. 输出均值、中位数、P95、P99 及超过 HBGV 的概率
```

- 分布选择应有数据依据（拟合检验）。
- 浓度低于检出限（LOD）时应采用适当替代方法（如 1/2 LOD、1/√2 LOD 或概率替代），并说明。

### 6.3 敏感性分析

| 方法 | 原理 | 用途 |
|---|---|---|
| 单因素（OAT） | 每次只变动一个参数，观察输出变化 | 快速筛查 |
| 相关系数/回归 | 输出与各输入的相关性 | 识别主导因子 |
| **Sobol 指数** | 方差分解：一阶指数 `Si` 度量单参数主效应；总效应指数 `STi` 含交互作用 | 定量参数与交互贡献 |
| 二维 Monte Carlo | 外层分离“变异性(variability)”与“不确定性(uncertainty)” | 区分人群真实差异与知识不足 |

Sobol 指数量式（概念）：

```
Si      = Var[E(Y | Xi)] / Var(Y)
STi     = 1 − Var[E(Y | X∼i)] / Var(Y)
Y 为模型输出（如暴露量或 HQ），Xi 为第 i 个输入
```

### 6.4 变异性 vs 不确定性

- **变异性（variability）**：人群真实的个体差异，不可通过增加数据消除，只能更好刻画。
- **不确定性（uncertainty）**：因知识不足导致，可通过更多数据/研究降低。
- 二维 Monte Carlo 将两者分开，避免混淆。

## 七、完整计算示例

> 以下所有数值均为**演示用假设值**，非真实限量/监测值。

### 示例 1：慢性点评估与 HQ（有阈值物质）

**假设**：危害物 X 的 ADI = 0.02 mg/kg bw/d；食品 A 中浓度均值 c̄ = 0.08 mg/kg、P95 = 0.25 mg/kg；消费量均值 CR = 0.12 kg/d、P95 = 0.35 kg/d；体重 BW = 60 kg。

```
一般人群（均值×均值）：
  EDI = (0.08 × 0.12) / 60 = 0.0096 / 60 = 1.6×10⁻⁴ mg/kg bw/d
  HQ  = 1.6×10⁻⁴ / 0.02 = 0.008  ( %ADI = 0.8% )

高消费/高端人群（P95浓度×P95消费）：
  EDI = (0.25 × 0.35) / 60 = 0.0875 / 60 = 1.458×10⁻³ mg/kg bw/d
  HQ  = 1.458×10⁻³ / 0.02 = 0.073  ( %ADI = 7.3% )
```

**结论**：一般人群与高端人群 HQ 均 < 1，暴露量低于 ADI，判为**可接受**；但需注意高端组合为保守估计。

### 示例 2：急性 IESTI（Case 2a）

**假设**：农药 P 的 ARfD = 0.05 mg/kg bw；食品 B（如苹果类）单位重 U = 0.10 kg，大份餐 LP = 0.50 kg，最高残留 HR = 0.30 mg/kg，变异系数 vf = 3，体重 BW = 60 kg。U（0.10）< LP（0.50），属 Case 2a。

```
IESTI = [U × HR × vf + (LP − U) × HR] / bw
      = [0.10 × 0.30 × 3 + (0.50 − 0.10) × 0.30] / 60
      = [0.09 + 0.12] / 60
      = 0.21 / 60
      = 3.5×10⁻³ mg/kg bw

%ARfD = IESTI / ARfD = 3.5×10⁻³ / 0.05 = 7.0%
```

**结论**：急性暴露为 ARfD 的 7%，**远低于**急性参考剂量，判为**可接受**。

### 示例 3：MOE（无阈值，遗传毒性致癌物）

**假设**：致癌物 Y 的 BMDL₁₀ = 0.5 mg/kg bw/d（动物致癌试验）；膳食暴露量 = 5×10⁻⁵ mg/kg bw/d。

```
MOE = BMDL₁₀ / 暴露量 = 0.5 / (5×10⁻⁵) = 10 000
```

**结论**：MOE 恰为 10 000，处于“低健康关注”参照线下限/边界，判为**需关注**；应结合暴露不确定性、研究质量与种间/人群变异综合解读，必要时降低暴露。

### 示例 4：ILCR（致癌风险）

**假设**：致癌物 Z 的经口斜率因子 SF = 0.5 (mg/kg bw/d)^-1；慢性日暴露 CDI = 2×10⁻⁵ mg/kg bw/d。

```
ILCR = CDI × SF = 2×10⁻⁵ × 0.5 = 1×10⁻⁵
```

**结论**：ILCR = 1×10⁻⁵，落在 10⁻⁶~10⁻⁴ 的关注区间，判为**需关注**（注意：此为特定管理场景指标，食品安全评估通常优先采用 MOE/HQ）。

## 公式与参数速查表

### 核心公式

| 名称 | 公式 | 说明 |
|---|---|---|
| 膳食暴露量 | `暴露 = Σ(浓度 × 消费量) / 体重` | 基本式，单位 mg/kg bw/d |
| 健康指导值 | `HBGV = POD / UF` | POD 为 NOAEL/BMDL 等 |
| 默认不确定系数 | `UF = 10(种间) × 10(种内) = 100` | 动物外推到人 |
| 危害商 | `HQ = 暴露量 / ADI(或TDI等)` | HQ ≤ 1 一般可接受 |
| 暴露边界 | `MOE = BMDL / 暴露量` | 致癌物常用 BMDL₁₀；MOE ≥ 10 000 通常低关注 |
| 致癌风险 | `ILCR = CDI × SF` | 关注区间约 10⁻⁶~10⁻⁴ |
| IESTI Case 1 | `(LP × HR) / bw` | 单位重 < 0.025 kg 等 |
| IESTI Case 2a | `[U × HR × vf + (LP − U) × HR] / bw` | U < LP |
| IESTI Case 2b | `(U × HR × vf) / bw` | U ≥ LP |
| IESTI Case 3 | `(LP × STMR) / bw` | 加工/混合产品 |
| BMD | 由剂量-反应模型拟合求得 | 计量资料 BMR 默认 5%，计数常用 10% |
| Sobol 一阶指数 | `Si = Var[E(Y|Xi)] / Var(Y)` | 参数主效应贡献 |
| Sobol 总效应 | `STi = 1 − Var[E(Y|X∼i)] / Var(Y)` | 含交互作用 |
