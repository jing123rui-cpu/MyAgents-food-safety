## 三、来源与可靠性说明

- **一级（权威）**：国家卫健委/国家食品安全风险评估中心（CFSA）、农业农村部、国家市场监管总局、国家标准全文公开系统、WHO/FAO/Codex、EFSA、US FDA。见各文件来源列表。
- **二级（参考）**：百科、行业媒体、检测服务机构科普文章；仅作科普性核对，规范性问题应回归一级来源。
- 各文件均设 **"待核实" 标注/清单**；标准版本更替较快，使用前须在官方平台按标准号复核。
- **限量判定**：以现行 GB 标准正文与配套检验方法（GB 5009 系列、GB 4789 系列、GB 8538 等）为准；进出口还需对照 Codex/目标市场要求。
- 农药/兽药登记与禁用清单以 **最新公告** 为准；风险结论应标注数据来源、假设与不确定度。
