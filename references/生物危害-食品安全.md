> 本文件面向食品安全风险评估、HACCP 危害分析与限量合规判定，整理食源性疾病主要致病菌、GB 29921 致病菌限量、预测微生物学、腐败与货架期、生物胺及控制措施。

> **使用说明**
> - 生长温度/pH/aw、D 值等为国际权威资料（WHO、ICMSF、FDA Bad Bug Book）与教材常见范围，**用于风险判断参考**；同一菌种不同菌株差异大，实际应以产品验证与检测数据为准。
> - 凡无法在本轮联网核实的数值，均标注**（待核实）**；标准限量以标准正文为准。

## 一、食源性疾病与主要致病菌

WHO 估计：全球每年约 8.66 亿人因食用受污染食品患病、约 152 万人死亡；5 岁以下儿童承担约 29% 的疾病负担。食源性疾病中，腹泻病最常见，沙门氏菌、弯曲菌、产志贺毒素大肠埃希氏菌（STEC）与志贺氏菌是四大细菌性腹泻病因。以下逐菌种说明。

### 1.1 沙门氏菌（Salmonella）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阴性杆菌（肠杆菌科）；*S. bongori* 与 *S. enterica* 两物种，已鉴定 **>2500 种血清型**；干燥环境可存活数周、水中数月；对热敏感 |
| 感染剂量 | 因血清型/食品基质差异大，低至 **10¹–10² CFU** 即可致病（高脂/低水活食品尤甚），一般引用的致病剂量范围 10¹–10⁶ CFU（待核实具体阈值） |
| 常见食品载体 | 蛋及蛋制品、禽肉、肉制品、生乳及乳制品、被粪便污染的绿叶蔬菜；可经饲料→生产→家庭整条链传播 |
| 生长范围 | 温度 **5.2–46.2 ℃**（最适 35–37 ℃）；pH **3.8–9.5**（最适 6.5–7.5）；aw **≥0.94**（最低约 0.93） |
| 潜伏期 | 6–72 h（通常 12–36 h），病程 2–7 天 |
| D 值 | D₆₀℃ 约 0.2–4 min（随基质变化）；彻底加热（中心 ≥70 ℃）可灭活 |
| 关键控制点（CCP） | ① 蛋/禽肉/肉彻底加热至中心 ≥70 ℃；② 全程冷链（0–4 ℃）；③ 生熟分开、防交叉污染；④ 食品从业人员带菌/腹泻时调离；⑤ 网购高水分即食食品认准冷链 |

### 1.2 单核细胞增生李斯特菌（Listeria monocytogenes）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阳性短杆菌；**可在冷藏温度（约 0–5 ℃甚至更低）存活并繁殖**；耐盐、耐酸、耐冷，对常见防腐手段（盐渍、烟熏、酸性环境）抵抗力强 |
| 感染剂量 | 高危人群感染剂量可能较低（部分资料引用 <1000 CFU，甚至 10² CFU 级）（待核实）；致病性取决于菌株与宿主免疫状态 |
| 常见食品载体 | 即食肉制品（熟制/腌制/发酵香肠、火腿、肉酱 pâté）、软质奶酪、未巴氏杀菌乳及冰淇淋、冷熏鱼（烟熏三文鱼）、预切沙拉、生鲜果蔬 |
| 生长范围 | 温度 **-0.4–45 ℃**（最适 30–37 ℃）；pH **4.4–9.4**（最适约 7.0）；aw **≥0.90** |
| 潜伏期 | 侵袭型通常 1–2 周，可短至数天、长达 90 天；非侵袭型（发热性胃肠炎）数天 |
| 病死率 | 侵袭型高达 **20–30%**（WHO）；孕妇感染风险约为健康成人 20 倍 |
| 关键控制点（CCP） | ① 巴氏杀菌/热加工（可杀灭）；② 冷藏且严格控制货架期（冷藏不能抑制其繁殖）；③ 即食食品的**李斯特菌环境监测**（寻找并消除加工环境生态位）；④ 高危人群避免软奶酪、即食肉、冷熏鱼 |

### 1.3 产志贺毒素大肠埃希氏菌 O157:H7（STEC / EHEC）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阴性杆菌；产生志贺毒素 Stx1/Stx2；**对热敏感**；O157:H7 为公共卫生意义最重要的血清型 |
| 感染剂量 | **极低，10–100 CFU 即可致病** |
| 常见食品载体 | 未煮熟碎牛肉（汉堡）、生乳及生乳制品、生鲜叶菜与芽苗、未巴氏杀菌苹果汁、被粪便污染的水（含娱乐用水） |
| 生长范围 | 温度 **7–50 ℃**（最适 37 ℃）；可在酸性食品生长，**pH 最低 4.4**；**aw 最低 0.95**（WHO） |
| 潜伏期 | 3–8 天（中位 3–4 天）；病程约 10 天内自愈 |
| 危害后果 | 约 **10% 患者可发展为溶血性尿毒综合征（HUS）**，HUS 病死率 3–5%；抗生素可能增加 HUS 风险，不推荐 |
| 关键控制点（CCP） | ① 肉品彻底加热至中心 ≥70 ℃；② 不饮生乳、不食生芽苗；③ 屠宰卫生、防止粪污交叉污染；④ 蔬果清洗/去皮，高风险人群避免生食 |

### 1.4 金黄色葡萄球菌及其肠毒素（Staphylococcus aureus）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阳性球菌；**耐盐（可在 10–15% NaCl 存活/生长）、耐低 aw**；人/动物皮肤、鼻腔、伤口携带；产毒株产生 A–E 等多种肠毒素（SEA–SEE） |
| 感染/中毒机制 | 主要为其**肠毒素**引起的中毒（非感染）；肠毒素**热稳定**，一般烹调与巴氏杀菌难以破坏 |
| 产毒剂量 | 食品中菌数达 **10⁵–10⁸ CFU/g** 时易产生致病剂量肠毒素；肠毒素本身为微克级即可致病（待核实精确剂量） |
| 常见食品载体 | 熟肉制品、乳制品、奶油糕点、剩饭/淀粉制品、沙拉、蛋制品 |
| 生长/产毒范围 | 生长温度 **6.5–46 ℃**（最适 30–37 ℃）；pH 4.0–9.8（产毒一般 pH >5）；生长 aw **≥0.86**，产毒 aw **≥0.87**（厌氧下更高） |
| 潜伏期 | 通常 **0.5–6 h**（毒素型，起病快） |
| 关键控制点（CCP） | ① **时间-温度控制**（熟食室温放置不超 2 h，快速冷却/冷藏）；② 手部与皮肤伤口卫生；③ 一旦产毒，加热不能去除，故以预防产毒为核心 |

### 1.5 副溶血性弧菌（Vibrio parahaemolyticus）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阴性**嗜盐**弧菌，天然存在于近海海水与海产品；致病相关毒力基因 tdh/trh，O3:K6 等血清型曾引起大流行 |
| 感染剂量 | 一般 **10⁵–10⁷ CFU**（取决于毒力基因与个体） |
| 常见食品载体 | 生的或未煮透的海产品（贝类、虾蟹、乌贼）、即食水产制品、生熟交叉污染 |
| 生长范围 | 温度 **5–44 ℃**（最适 30–37 ℃）；**嗜盐**，需 NaCl（最适约 2–4%，可耐受至 8–10%）；pH 4.8–11（最适 7.6–8.6） |
| 潜伏期 | 约 4–96 h，常 12–24 h |
| 关键控制点（CCP） | ① 海产品彻底加热（中心 ≥70 ℃）；② 低温冷藏并缩短存放；③ 严禁生熟交叉污染；④ 生食海产品属高风险，谨慎选择 |

### 1.6 弯曲菌（Campylobacter）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阴性、**微需氧**、螺旋/弯曲杆菌；*C. jejuni* 与 *C. coli* 最常见；被认为是全球最常见的细菌性胃肠炎病因 |
| 感染剂量 | 低，约 **500–10 000 CFU**（部分资料引用约 500 CFU 即可致病） |
| 常见食品载体 | 未煮熟禽肉（主要来源）、生乳、被污染的水/冰；宠物与农场动物接触亦为风险 |
| 生长范围 | 温度 **30–47 ℃**（最适 41–42 ℃，**低于 30 ℃通常不生长**但可存活）；pH 4.9–9.0（最适 6.5–7.5）；aw ≥0.95 |
| 潜伏期 | 2–5 天（范围 1–10 天）；病程 3–6 天 |
| 关键控制点（CCP） | ① 禽肉彻底加热（对热敏感，60 ℃可灭活）；② 防止禽肉汁液污染其他食品与砧板；③ 不饮生乳；④ 加强养殖端生物安全 |

### 1.7 蜡样芽胞杆菌（Bacillus cereus）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阳性**产芽孢**杆菌，土壤与淀粉类食品常见；产生两类毒素：**催吐毒素 cereulide（耐热，126 ℃ 90 min 仍稳定，待核实）**与致腹泻肠毒素（HBL/NHE，热不稳定） |
| 感染/中毒 | 腹泻型：摄入产毒菌/肠毒素；催吐型：摄入 preformed cereulide，常与剩饭相关 |
| 剂量 | 腹泻型常与 **10⁵–10⁶ CFU/g** 相关；催吐型因毒素已生成，无需大量活菌 |
| 常见食品载体 | 剩米饭/炒饭、面食、乳制品、酱汁、豆制品 |
| 生长/产毒范围 | 生长温度 **4–55 ℃**（最适 28–35 ℃）；pH 4.3–9.3；aw ≥0.92；产毒温度约 10–43 ℃ |
| 潜伏期 | 催吐型 **0.5–6 h**；腹泻型 6–24 h |
| 关键控制点（CCP） | ① 米饭/淀粉类熟后**快速冷却**并冷藏；② 室温放置不超过 2 h；③ 复热可杀灭菌体但**不能破坏 cereulide**，故以预防产毒为核心 |

### 1.8 肉毒梭菌（Clostridium botulinum）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阳性**厌氧**、产芽孢杆菌；产生 A–G 型肉毒毒素，人中毒主要为 A、B、E（少 F）型；**芽孢耐热**，毒素不耐热 |
| 毒素特性 | 肉毒毒素为已知最毒物质之一；**煮沸/内部 >85 ℃ 5 min 可破坏毒素**；芽孢需高温高压才能杀灭 |
| 中毒剂量 | 极低，纳克/千克体重级（吸入中毒人半数致死量约 2 ng/kg，约为食源性 3 倍） |
| 常见食品载体 | 自制低酸罐头/瓶装食品、发酵或盐渍鱼/肉、真空包装低酸食品、蜂蜜（婴儿肉毒） |
| 生长/产毒条件 | 厌氧；**pH <4.6 不生长**；aw 最低约 0.93（待核实）；温度 3–48 ℃（最适 30–37 ℃，E 型可在约 3.3 ℃生长） |
| 潜伏期 | 食源性 12–36 h（范围 4 h–8 天）；未及时治疗病死率 5–10% |
| 关键控制点（CCP） | ① 低酸罐头**商业无菌/高压灭菌**（121 ℃ 杀死芽孢）；② 酸化至 pH <4.6 或高盐/冷藏组合抑制；③ 真空包装低酸食品冷链；④ **1 岁以下婴儿禁食蜂蜜** |

### 1.9 志贺氏菌（Shigella）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 革兰阴性兼性厌氧杆菌；*S. dysenteriae*、*flexneri*、*boydii*、*sonnei*；经粪-口途径、人-人传播 |
| 感染剂量 | **极低，10–200 CFU**（*S. dysenteriae* 1 型约 10 个菌即可致病） |
| 常见食品载体 | 生鲜蔬果、凉拌即食沙拉、未巴氏杀菌乳制品、被污染的水 |
| 生长范围 | 温度 6–47 ℃（最适 37 ℃）；pH 5–9（最适 6.5–7.5）；aw ≥0.95；对热敏感（60 ℃可灭活） |
| 潜伏期 | 1–3 天（12 h–7 天）；*S. dysenteriae* 1 型可致 HUS |
| 关键控制点（CCP） | ① 从业人员手卫生（带菌者调离）；② 蔬果清洗/消毒；③ 安全饮用水；④ 即食食品冷链与卫生操作 |

### 1.10 诺如病毒（Norovirus）

| 项目 | 内容 |
|---|---|
| 生物学特性 | 杯状病毒科、**无包膜**单股 RNA 病毒；环境抵抗力强，对冷冻、加热和酸性有一定耐受；对含氯消毒剂较敏感（需足够浓度） |
| 感染剂量 | **极低，约 10–100 个病毒颗粒 / 18–1000 个病毒颗粒**（不同文献，待核实现行共识值） |
| 常见食品载体 | 生食贝类（尤其牡蛎）、即食食品（沙拉、三明治）、浆果、被污染的水；主要经**食品从业人员带毒操作**与呕吐物气溶胶传播 |
| 灭活条件 | 加热 90 ℃ 短时可灭活；60 ℃ 30 min 仅部分灭活；冷冻与一般冷藏不能灭活（待核实具体参数） |
| 潜伏期 | 12–48 h（常 24–48 h）；病程 12–60 h |
| 关键控制点（CCP） | ① 从业人员健康管理与带症状不上岗；② 贝类来源、净化与彻底加热；③ 严格执行洗手；④ 环境与器具含氯消毒；⑤ 生食沙拉/贝类属高风险 |

> 说明：金黄色葡萄球菌肠毒素、蜡样芽胞杆菌 cereulide、肉毒毒素均属"毒素型"危害，热加工不能消除已形成的毒素，控制重心在**抑制产毒**（时间-温度/aw/pH）。

## 二、GB 29921 致病菌限量：采样方案 n/c/m/M 解读与应用

**适用标准**：GB 29921-2021《食品安全国家标准 预包装食品中致病菌限量》（2021-11-22 实施）；散装即食食品参照 GB 31607-2021。两标准均不适用于执行商业无菌要求的食品、包装饮用水、饮用天然矿泉水等。

### 2.1 n、c、m、M 含义

| 符号 | 含义 |
|---|---|
| **n** | 同一批次产品应采集的**样品件数** |
| **c** | 允许**超过 m 值（但不超过 M 值）**的样品最大允许件数；c=0 表示一件都不允许 |
| **m** | 致病菌**可接受水平限量值**（三级采样方案）或**最高安全限量值**（二级采样方案） |
| **M** | 致病菌**最高安全限量值**（三级采样方案上限） |

- **二级采样方案**（n, c, m）：只设 m，通常 c=0，用于"不得检出"型指标（如沙门氏菌、单增李斯特菌、致泻大肠埃希氏菌）。
- **三级采样方案**（n, c, m, M）：设 m、M 两个限值，用于可定量且允许一定波动的指标（如金黄色葡萄球菌、副溶血性弧菌）。

### 2.2 判定规则

1. 二级方案：若 **任一件样品检出**（>m，m 常为 0/25 g），则**整批不合格**。
2. 三级方案：先数超过 m 的样品件数 **s**：
   - s ≤ c 且无任一件 >M → **合格**；
   - s > c，或任一件 >M → **不合格**。
3. 每件样品**独立检测**，标准一般不允许将多件样品混合后检测（除非标准另有规定）。
4. 采样应有代表性，通常无菌操作、按标准规定采样量与稀释度（如 25 g 样品 + 225 mL 稀释液）。

### 2.3 常见指标与限量（示例，具体类别以标准正文为准）

| 致病菌 | 采样方案（n,c,m,M） | 限量 | 适用食品类别（示例） |
|---|---|---|---|
| 沙门氏菌 | 5, 0, 0/25 g | 不得检出 | 多数即食/预包装食品 |
| 单核细胞增生李斯特氏菌 | 5, 0, 0/25 g | 不得检出 | 标准规定的即食肉制品、即食水产、生食果蔬汁等 |
| 致泻大肠埃希氏菌 | 5, 0, 0/25 g | 不得检出 | 标准规定的熟肉制品、水产制品等 |
| 金黄色葡萄球菌 | 5, 1, 100 CFU/g, 1000 CFU/g | ≤100 为 m，1000 为 M | 标准规定的即食食品 |
| 副溶血性弧菌 | 5, 1, 100 MPN/g, 1000 MPN/g | ≤100 为 m，1000 为 M | 水产制品、即食海产品 |
| 克罗诺杆菌属（阪崎肠杆菌） | 3, 0, 0/100 g | 不得检出 | 婴儿配方食品等特殊膳食 |

> **重要提示**：上表为常见值示例，**各指标对应的具体食品类别与限量必须逐项核对 GB 29921-2021 正文**。标准仅覆盖规定的预包装食品类别，未列入的食品应执行相应产品标准或企业内控。

## 三、预测微生物学（Predictive Microbiology）

预测微生物学用数学模型描述食品中微生物在环境条件下的生长/死亡，用于货架期预测、工艺设计和风险定量评估。

### 3.1 生长动力学模型（初级模型）

描述菌数随时间的 S 形变化，参数：N₀（初始菌数，log CFU/g）、Nmax（最大菌数密度）、μmax（最大比生长速率，1/h）、λ（延滞期，h）。

| 模型 | 形式（要点） | 特点 |
|---|---|---|
| **Logistic（修正）** | N(t)=N₀ + (Nmax−N₀)/{1+exp[(4μmax/(Nmax−N₀))·(λ−t)+2]} | 对称 S 曲线，参数直观 |
| **Gompertz（修正）** | log N(t)=A + C·exp{−exp[−B(t−M)]} | A 为初始对数菌数、C 为增长幅度、B 与 M 为速率/拐点；拟合微生物生长较好 |
| **Baranyi & Roberts** | 以"调整函数"α(t) 描述逐渐适应，再叠加指数生长 | 能更真实反映延滞期与平滑过渡，常用于 ComBase |

### 3.2 热致死动力学（次级/失活模型）

| 参数 | 定义 | 关系式 |
|---|---|---|
| **D 值** | 在某一温度下使菌数（或芽孢数）下降 **90%（1 个对数级）**所需时间（min） | D = 2.303 / k（k 为一级失活动力学速率常数） |
| **z 值** | 使 **D 值变化 10 倍**所需改变的温度（℃） | log(D₁/D₂) = (T₂−T₁)/z |
| **F 值** | 在给定温度下，达到规定杀菌效果所需的时间（min） | F = ∫L dt；**F₀**：以 121.1 ℃、z=10 ℃ 为参比的等效杀菌时间 |
| **致死率 L** | 某温度相对参比温度的杀菌效力 | L = 10^[(T−Tref)/z]，F = ∑(L·Δt) |

设计思路：由目标灭菌对数（如罐头肉毒梭菌 12D）反推所需温度-时间组合；例如 F₀ ≥ 3 min 常作为低酸罐头商业无菌的重要指标。

### 3.3 温度–pH–aw 交互（次级模型）

- **Gamma 概念（栅栏/γ 模型）**：μmax = μopt·γ(T)·γ(pH)·γ(aw)·γ(…)，各 γ∈[0,1]，反映单因子对生长的抑制程度，可组合多因子。
- **Cardinal 参数模型**：以 Tmin/Topt/Tmax、pHmin/pHopt/pHmax、aw min/aw opt 等基数参数刻画生长边界。
- **生长/非生长界面（growth/no-growth boundary）**：用于识别栅栏技术的"安全区"。
- **常用工具**：ComBase、USDA PMP、DMFit、R 语言 `growthrates` 等。

**温度-pH-aw 交互要点**：低 aw 会**升高**最适生长温度并**收窄**pH 生长范围；酸化可降低耐热芽孢的耐热性；冷藏与低 aw/低 pH/防腐剂组合（栅栏）可协同抑制，单一因子往往不足。

## 四、腐败微生物与货架期

腐败微生物不直接等同致病菌，但决定货架期，并可作为卫生/冷链失控的指示。

| 腐败菌类群 | 主要食品 | 特点/代谢产物 |
|---|---|---|
| 假单胞菌（*Pseudomonas*） | 需氧冷藏的肉、禽、鱼、乳 | 嗜冷、需氧，产生黏液、异味、色素 |
| 乳酸菌（LAB） | 真空包装肉、发酵食品 | 耐厌氧/高 CO₂，产酸、产气、发粘 |
| *Brochothrix thermosphacta* | 真空/MAP 包装肉 | 嗜冷，产生奶酪样/酸败气味 |
| 肠杆菌科 | 肉、鱼、冷藏食品 | 卫生指示菌，产胺、产气 |
| 酵母与霉菌 | 低 aw/酸性/高糖食品 | 耐渗透压、耐酸，产霉味/毒素 |
| 嗜热菌 | 高温贮藏或热加工后 | 嗜热芽孢，导致罐头/乳品腐败 |

**货架期预测**：
- 微生物货架期 ≈ 达到腐败阈值所需时间，可用初级生长模型推算：由 N₀ 到 N_阈值（如 10⁶–10⁷ CFU/g）所需时间（含延滞期 λ）。
- 关键影响因素：**初始菌数、贮藏温度、aw、pH、包装气氛（真空/MAP）、防腐剂与竞争菌群**。
- 冷链断裂会显著缩短货架期；假单胞菌等嗜冷菌在 0–4 ℃仍可缓慢生长，是冷藏食品腐败主因。

## 五、生物胺与食品中毒

### 5.1 概述

- **生物胺（Biogenic amines）**：具有生物活性的低分子含氮有机化合物，包括**组胺、酪胺、尸胺、腐胺、精胺、亚精胺、苯乙胺、色胺**等。
- **生成机制**：微生物（肠杆菌、部分乳酸菌、假单胞菌等）产生的**氨基酸脱羧酶**催化游离氨基酸脱羧；与原料新鲜度、卫生状况和温度滥用密切相关。
- **高风险食品**：发酵鱼/鱼露/鱼酱、**高组氨酸鲭科鱼**（鲐鱼、鲭鱼、沙丁鱼、凤尾鱼、金枪鱼）、奶酪、发酵肉制品、葡萄酒、酸菜、豆酱等。

### 5.2 组胺中毒（鲭鱼中毒，scombroid poisoning）

| 项目 | 内容 |
|---|---|
| 机制 | 鱼类死亡后，组氨酸被细菌脱羧生成组胺；**加热不能消除已生成的组胺** |
| 症状 | 数分钟至数小时起病：面部潮红、头痛、心悸、口唇麻木、荨麻疹、腹泻；类似过敏反应 |
| 敏感阈值 | 组胺 >50 mg/kg 可使敏感个体不适；**总生物胺 >1000 mg/kg** 通常认为有害；组胺 100–200 mg/kg 可能引发中毒（不同文献，待核实） |

### 5.3 限量与检测

| 依据 | 限量/要求 |
|---|---|
| 欧盟（EU）| 鲭科等鱼类产品组胺 **200 mg/kg**；经酶成熟处理的水产品 **400 mg/kg**（依据 EC 2073/2005，待核实最新修订） |
| 美国 FDA | 组胺 **50 ppm** 判定为腐败缺陷（decomposition）；**100–200 ppm** 可能引起中毒 |
| 中国 | GB 5009.208-2016《食品安全国家标准 食品中生物胺的测定》为检测方法；**水产制品组胺限量**见相应产品标准（具体数值**待核实**，需查 GB 10136 等） |

### 5.4 控制措施

1. **快速冷链**：捕捞后立即冰鲜/冷冻，**尤其>15 ℃时组胺生成迅速**；控制 0–4 ℃。
2. 及时去内脏、放血，减少游离组氨酸与产酶菌。
3. 规范卫生操作，减少脱羧酶菌污染。
4. 发酵工艺控制（盐度、温度、接种发酵剂抑制产胺菌）。
5. 注意：**已生成的组胺耐热，烹调无法去除**，故预防是关键。

## 六、控制措施（热杀菌、冷链、aw、pH、栅栏技术）

### 6.1 热杀菌

| 方式 | 典型参数 | 目标 |
|---|---|---|
| 巴氏杀菌 | 72–75 ℃ / 15 s（乳） | 杀灭营养细胞（李斯特菌、沙门氏菌等），不杀灭芽孢 |
| 高温短时/UHT | 135–150 ℃ / 数秒 | 商业无菌乳制品 |
| 商业无菌（低酸罐头） | 121 ℃ 左右，F₀ ≥ 3 min | 杀灭肉毒梭菌芽孢（12D 概念） |
| 烹饪/复热 | 中心温度 ≥70 ℃ | 杀灭沙门氏菌、STEC、弯曲菌等；**不能消除已生成的毒素** |

设计依据：D 值、z 值、F 值（见第三节），并结合目标菌与初始菌数确定杀菌强度。

### 6.2 冷链与时间-温度控制

- 冷藏 **0–4 ℃**、冷冻 **≤-18 ℃**（CFSA 夏季提示）。
- 熟食/易腐食品室温存放 **≤2 h**；剩饭菜及时冷藏并彻底复热。
- 单增李斯特菌、嗜冷腐败菌在冷藏下仍能生长 → 必须**同时控制货架期**。

### 6.3 水分活度（aw）

| aw | 微生物学意义 |
|---|---|
| <0.60 | 绝大多数微生物不能生长（耐旱霉菌/酵母除外） |
| 0.60–0.85 | 多数细菌不生长；金葡菌可至 0.86、部分霉菌/酵母可生长 |
| ≥0.85–0.90 | 多数致病菌可生长（李斯特菌约 0.90，沙门氏菌约 0.94） |

手段：干燥、浓缩、加盐/糖（栅栏）、冷冻干燥。

### 6.4 pH 控制

- **pH <4.6**：抑制肉毒梭菌生长与产毒，是低酸/酸化食品分界。
- 发酵产酸（乳酸、醋酸）降低 pH 并产生抑菌作用。
- 注意：酸化对已形成的毒素无破坏作用。

### 6.5 栅栏技术与防腐

**栅栏（Hurdle）技术**：将多个温和抑菌因子组合，使微生物无法逾越，实现稳定与安全。

| 栅栏因子 | 示例 |
|---|---|
| 温度 | 冷藏、冷冻、热处理 |
| aw | 盐渍、糖渍、干燥 |
| pH/酸度 | 酸化、发酵 |
| 氧化还原电位 | 真空/充氮包装、除氧剂 |
| 竞争菌群 | 发酵剂、保护性培养物 |
| 防腐剂 | 亚硝酸盐（肉制品，抑制肉毒梭菌）、山梨酸钾、苯甲酸钠、纳他霉素（表面防霉） |
| 其他 | 气调包装（MAP）、高压处理（HPP）、辐照、超高压/脉冲电场 |

### 6.6 通用卫生与人员管理（WHO 食品安全五要点）

1. 保持清洁（洗手、器具消毒）。
2. 生熟分开（砧板、容器、存放分区）。
3. 烧熟煮透（中心 ≥70 ℃）。
4. 在安全温度下保存（冷藏/热藏）。
5. 使用安全的水和原料。
