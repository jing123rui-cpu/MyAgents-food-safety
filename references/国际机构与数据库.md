## 二、CAC / Codex Alimentarius：国际食品标准体系

### 2.1 性质与地位
- 1963 年由 FAO 与 WHO 共同创建，现有成员覆盖全球大多数国家和地区。
- 其标准、准则和操作规范是 WTO《实施卫生与植物卫生措施协定》（SPS）和《技术性贸易壁垒协定》（TBT）认可的国际参考基准。
- 标准制定以"风险评估 + 政府间协商"为基础，属自愿性标准，但常被各国转化为国内法规。

### 2.2 主要文本类型

| 文本类型 | 英文 | 内容与作用 |
|---|---|---|
| 食品标准 | Codex Standards | 针对具体食品/商品的质量、安全与标签要求（如乳制品、油脂、谷物、水产品等） |
| 操作规范 | Codes of Practice | 卫生规范与污染物防控的推荐做法（如霉菌毒素预防、兽药使用） |
| 准则 | Guidelines | 风险分析、营养标签、食品检验与认证等原则性指南 |
| 最大残留限量 | Maximum Residue Limits (MRLs) | 农药、兽药在食品中的最大残留限量 |
| 程序手册 | Procedural Manual | Codex 议事规则、标准制定流程与风险分析原则 |

### 2.3 风险评估原则（Codex 框架）
- 风险分析由三部分组成：风险评价（risk assessment）、风险管理（risk management）、风险交流（risk communication）。
- 风险评价包括：危害识别 → 危害特征描述 → 暴露评估 → 风险特征描述。
- Codex 下属通用专题委员会（如食品添加剂 CCFA、农药残留 CCPR、兽药残留 CCRVDF、污染物 CCFC、食品卫生 CCFH、营养与特殊膳食用食品 CCNFSDU、标签 CCFL）负责起草，交由委员会（CAC）通过。
- 科学建议主要来自 FAO/WHO 专家机构（JECFA、JMPR、JEMRA 等）或 FAO/WHO 联合专家磋商。

### 2.4 在线数据库
- 农药残留数据库（Pesticide Database / Pest Res）
- 兽药残留数据库（Veterinary Drugs Database）
- 食品添加剂数据库（GSFA Online，Codex General Standard for Food Additives）

网址入口：https://codex.fao.org/codex-texts/dbs （旧站点 https://www.fao.org/fao-who-codexalimentarius/ 已于 2026-08-31 停更并跳转）

## 三、JECFA / JMPR：专家委员会的评估结论与产出

### 3.1 JECFA（食品添加剂联合专家委员会）
- 成立：1956 年，FAO 与 WHO 共同管理，最初评估食品添加剂，现扩展至污染物、天然毒物和兽药残留。
- 评估对象：食品添加剂、调味物质、加工助剂、污染物（如铅、镉、砷、汞）、天然毒素（如霉菌毒素）、兽药残留。
- 主要产出：
  - 会议报告（如第 100、101、102 次会议报告，2025–2026 年发布）；
  - 毒理学专著（Toxicological Monographs）；
  - 摘要报告（Summary and Conclusions）。
- 关键健康指导值：
  - **ADI**（Acceptable Daily Intake，每日允许摄入量）：以 mg/kg 体重/天表示，如阿斯巴甜 ADI 为 0–40 mg/kg 体重（JECFA 2023 年重申）。
  - 对急性毒性物质，可能设定急性参考剂量（ARfD）或"临时 ADI"。
- 官方数据库：https://apps.who.int/food-additives-contaminants-jecfa-database/

### 3.2 JMPR（农药残留联席会议）
- 性质：FAO 与 WHO 联合的专家会议，统一农药残留风险评估要求。
- 组成分工：FAO 专家组负责残留与暴露评估、推荐 MRL；WHO 核心评估组负责毒理学评估、制定 ADI/ARfD。
- 评估流程简述：毒理学 → 确定 ADI/ARfD → 膳食暴露评估 → 提出 MRL 建议 → 提交 Codex CCPR 审议采纳。
- 主要产出：农药残留报告、毒理学专著、摘要报告；为 Codex 制定 MRLs 提供科学依据。
- 官方数据库（评估清单）：https://apps.who.int/pesticide-residues-jmpr-database

### 3.3 三者关系
| 概念 | 含义 | 典型来源 |
|---|---|---|
| ADI | 每日允许摄入量（终生摄入不产生可觉察健康风险） | JECFA（添加剂/污染物）、JMPR（农药） |
| ARfD | 急性参考剂量（24 小时内摄入不产生健康风险） | JMPR、JECFA |
| MRL | 食品中最大残留限量（源自良好农业/兽医规范） | JMPR 建议 → Codex 采纳；兽药由 JECFA 建议 → Codex |
| 食品添加剂最大使用量 | 按良好生产规范（GMP）或按食品类别规定 | JECFA → Codex GSFA |

## 四、EFSA：欧盟科学意见、暴露评估与风险沟通

- 性质：欧盟独立的食品安全风险评估机构，总部在意大利帕尔马；负责风险评估，**不负责风险管理**（风险管理由欧盟委员会、成员国及欧盟其他机构承担）。
- 主要职能：
  - 就食品与饲料安全、营养、新型食品、食品接触材料、农药、食品添加剂、GMO、动物健康与福利等出具**科学意见（Scientific Opinions）**；
  - 开展**膳食暴露评估**（如 DietEx 工具）；
  - 进行危害识别与特征描述、剂量—反应评估与暴露评估；
  - **风险沟通**：面向公众、媒体和利益相关方的信息发布。
- 主要产物与平台：
  - EFSA Journal（开放获取期刊，发布全部科学产出）：https://efsa.onlinelibrary.wiley.com/
  - OpenEFSA（风险评估进程与数据门户）：https://open.efsa.europa.eu
  - Connect（与利益相关方互动平台）
- 官网：https://www.efsa.europa.eu/en
- 关注主题：化学污染物、农药、食品添加剂、QPS（安全资格认定）、食源性人兽共患病等。
- 与欧盟法规衔接：EFSA 意见通常服务于欧盟委员会的风险管理决策，最终以欧盟法规（EUR-Lex 公布）形式实施。

## 五、美国：FDA 与 USDA FSIS

### 5.1 US FDA（食品药品管理局）
- 监管范围：约占美国食品供应的绝大部分（肉类、禽类、部分蛋制品由 FSIS 监管）。
- 核心制度与法规：
  - **FSMA（Food Safety Modernization Act，食品安全现代化法案，2011）**：由"事后应对"转向"预防为主"，建立预防性控制、农产品安全、外国供应商验证、第三方审核、故意掺假防护等规则。
  - **GRAS（Generally Recognized as Safe，一般认为安全）**：依据《联邦食品、药品和化妆品法》第 201(s) 和 409 条，经科学训练并有经验的专家普遍认为安全的物质可豁免食品添加剂审批；含 GRAS 通知（GRAS Notice）程序。
  - **21 CFR（联邦法规第 21 篇）**：食品与药品法规，如 21 CFR Part 182《一般认为安全的物质》（Substances Generally Recognized as Safe，含香辛料、精油、防腐剂、营养素等列表）。eCFR 在线查看：https://www.ecfr.gov/current/title-21/chapter-I/subchapter-B/part-182
- 官网：https://www.fda.gov/food
- 说明：FDA 站点对部分自动抓取有访问限制，具体栏目路径使用前请以站内检索为准（待核实）。

### 5.2 USDA FSIS（食品安全检验局）
- 隶属美国农业部，监管**肉类、禽类及部分蛋制品**的安全、卫生与标签，依法实施检验。
- 主要工作：驻厂检验、HACCP 体系验证、致病菌（如沙门氏菌、弯曲菌、大肠杆菌 O157:H7）限量与绩效标准、产品召回与公众警示。
- 官网：https://www.fsis.usda.gov/
- 相关法规：9 CFR 等（待核实具体条款）。

### 5.3 欧盟法规体系（补充）
- 欧盟《通用食品法》：Regulation (EC) No 178/2002，确立食品法一般原则与要求、设立 EFSA、规定食品安全程序。参见 EUR-Lex：https://eur-lex.europa.eu/eli/reg/2002/178/oj
- 其他重要法规涉及食品卫生、动物源性食品卫生检验、污染物、添加剂、农残、兽药残留等（具体编号与最新修订以 EUR-Lex 为准，待核实）。
- **方法/抽样侧与限量侧的分工（涉外批次引用要点）**：
  - **(EU) 2023/2782** ＝ 委员会关于**霉菌毒素等污染物**抽样与分析方法的法规（2023-12-13）；其中"最大水平（ML）"取自 **(EU) 915/2023**（污染物最大水平）。
  - **农药残留多残留**的实验室性能判据（回收率 70–120%、RSD ≤ 20%、LOQ ≤ 0.5×MRL）属 **SANTE 指南／欧盟农药手册**语境，**不在 (EU) 2023/2782 适用范围**内——**法规号不得混引**（本库语境见 `质谱专家/references/证据条目与出处.md` **M-3**、`食品安全专家/references/化学危害-食品安全.md` 使用提示 4）。
  - ⚠️ 两部欧盟法规的**现行原文本库未取得**（EUR-Lex 抓取失败），数值系由 MDPI 分析专著转引；**对外出具前须经 EUR-Lex 逐条核对版本与编号**。

## 六、IARC 致癌物分级及食品相关举例

### 6.1 分级定义（IARC Monographs）

| 组别 | 含义 | 类别含义 |
|---|---|---|
| 1 类 | 对人类致癌（Carcinogenic to humans） | 有充分证据证明对人致癌 |
| 2A 类 | 很可能对人类致癌（Probably carcinogenic） | 对人证据有限、对实验动物证据充分 |
| 2B 类 | 可能对人类致癌（Possibly carcinogenic） | 对人证据有限、动物证据不充分等 |
| 3 类 | 尚不能对人类致癌性进行分类（Not classifiable） | 证据不足 |

> 规模：截至 2026-07-03 更新的《IARC Monographs Volumes 1–142》清单，1 类共 135 种、2A 类 98 种、2B 类 329 种、3 类 498 种。完整分级以 IARC 官方清单为准：https://monographs.iarc.who.int/agents-classified-by-the-iarc/

### 6.2 食品与膳食相关举例（常见、广为引用）

| IARC 组别 | 食品/膳食相关举例 | 备注 |
|---|---|---|
| 1 类 | 酒精饮料；黄曲霉毒素（Aflatoxins）；加工肉制品（如培根、火腿、香肠）；中式咸鱼；槟榔（Areca nut） | 加工肉制品与中式咸鱼为 2015 年前后评估；黄曲霉毒素为天然毒素 |
| 2A 类 | 红肉（牛肉、羊肉、猪肉等）；丙烯酰胺（Acrylamide）；65℃ 以上很热的饮料；夜班工作（非食品） | 红肉与很热饮料为 2015–2016 年评估；丙烯酰胺 1994 年评估 |
| 2B 类 | 阿斯巴甜（Aspartame，2023）；赭曲霉毒素 A（Ochratoxin A）；伏马菌素 B1（Fumonisin B1）；黄曲霉毒素 M1；亚洲传统盐腌蔬菜 | 阿斯巴甜于 2023-07 由 IARC 第 134 次会议列为 2B，JECFA 同期重申 ADI 0–40 mg/kg 体重 |

> 重要提示：IARC 分级反映"证据强度"，不代表在通常摄入水平下的致癌风险大小；风险管理需结合 JECFA/JMPR 等的暴露与风险评估结论。上表为常见举例，具体分类、评估卷次与更新状态请以 IARC 官方清单为准（部分条目存在分组调整，如 2022 年 HPV、焊接紫外辐射等）。

## 八、与我国 GB 标准体系的衔接

### 8.1 组织与标准层面衔接
- 中国是 Codex Alimentarius Commission 成员国，参与国际标准制定；中国承担 Codex 相关专业委员会主持工作（如食品添加剂、农药残留等委员会，具体主持国别以 Codex 官网为准）。
- 制定国内标准时，通常以 Codex 标准、JECFA/JMPR 评估结论为主要国际参考，结合我国膳食暴露与产业实际确定限量。

### 8.2 主要对应关系（示例）

| 我国标准/制度 | 主要内容 | 国际对标参考 |
|---|---|---|
| 《中华人民共和国食品安全法》 | 食品安全基本法律，确立风险评估与标准制度 | Codex 风险分析原则、WHO/FAO 食品控制体系框架 |
| GB 2760《食品安全国家标准 食品添加剂使用标准》 | 食品添加剂品种、使用范围与最大使用量 | Codex GSFA、JECFA 评估结论 |
| GB 2762《食品安全国家标准 食品中污染物限量》 | 铅、镉、砷、汞、真菌毒素等污染物限量 | Codex 污染物标准、JECFA 评估 |
| GB 2763《食品安全国家标准 食品中农药最大残留限量》 | 农药 MRL | Codex MRLs、JMPR 评估 |
| GB 31650《食品安全国家标准 食品中兽药最大残留限量》 | 兽药 MRL | Codex 兽药 MRLs、JECFA 兽药评估 |
| GB 29921《食品安全国家标准 预包装食品中致病菌限量》 | 致病菌限量 | Codex 食品卫生通则（CXC 1）与微生物风险准则（JEMRA） |
| GB 7718《食品安全国家标准 预包装食品标签通则》 | 预包装食品标签要求 | Codex 食品标签通用标准 |
| GB 14880《食品安全国家标准 食品营养强化剂使用标准》 | 营养强化剂用量 | Codex 营养与特殊膳食用食品标准 |
| 国家食品安全风险评估中心（CFSA） | 承担我国食品安全风险评估、监测与技术支撑 | 对应 EFSA/JECFA 等评估职能 |

> 说明：以上标准编号与名称为民用常见版本，标准会持续修订（部分已换版，如食品添加剂与农残限量标准多次整合修订）。实际引用时请核对现行有效版本及发布日期（待核实具体版次）。

### 8.3 应用建议
1. **限量比对**：国内限量与国际不一致时，优先以我国现行强制性 GB 标准判定合规；出口食品需同时满足目的国法规与 Codex 参考。
2. **风险排序**：可结合 JECFA/JMPR 的 ADI/ARfD、GEMS/Food 与我国膳食消费量数据开展暴露评估与风险排序。
3. **致癌性关注**：涉及 IARC 分级物质时，区分"危害分级"与"风险"，以 JECFA/JMPR 或 CFSA 的风险评估结论指导管理。
4. **法规溯源**：欧盟、美国等市场准入问题，分别经 EUR-Lex、eCFR/FDA 与 FSIS 官网核对原文。
