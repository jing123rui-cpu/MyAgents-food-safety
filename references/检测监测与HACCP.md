# 食品安全检测、监测与 HACCP 知识库

> 本文件面向食品安全风险评估与合规判定，汇集抽样方案、监测数据统计分析、检测方法与确证、HACCP 体系、CCP 判定、ISO 22000/GMP/SSOP 关系、企业自检与召回等内容。
> 标注说明：**标准号/条款以现行官方发布版本为准**；凡未能核实到原文的年份、令号、限量数值，均标注「待核实」，不得作为执法或判决的唯一依据。

## 一、抽样方案

### 1.1 抽样的基本类型

| 类型 | 适用场景 | 要点 |
|---|---|---|
| 简单随机抽样 | 批内单位产品无差异、总体可编号 | 每批/每单位被抽概率相等，代表性强 |
| 分层抽样 | 风险监测按地区、品类、企业规模、时间分层 | 层内同质、层间异质，先分层再随机，可提高效率 |
| 整群/多级抽样 | 大宗农产品、跨区域流通食品 | 先抽批次/门店/产区，再抽单位产品 |
| 系统抽样（等距） | 流水线连续生产 | 按固定间隔抽取，注意周期效应 |
| 判断/方便抽样 | 应急、靶向执法 | 非概率抽样，**不能推断总体**，仅作线索 |

### 1.2 计量抽样与计数抽样

- **计数抽样（attributes）**：只判定单位产品"合格/不合格"，依据**不合格品数**与判定数组（Ac, Re）决定批接收与否。适合感官、标签、微生物计数（合格/不合格）等离散特性。
- **计量抽样（variables）**：测定**连续量值**（如某污染物浓度、水分、净含量），用均值/标准差与规格限比较，同样样本量下信息量更大，但要求分布假定（通常正态）。
- **GB/T 2828 系列**（计数抽样检验程序，采标 ISO 2859 系列）：
  - **GB/T 2828.1-2012**《计数抽样检验程序 第1部分：按接收质量限(AQL)检索的逐批检验抽样计划》（现行，2012-11-05 发布，2013-02-15 实施，采标 ISO 2859-1）。
  - **GB/T 2828.3-2008**《第3部分：跳批抽样程序》（采标 ISO 2859-3:2005）。
  - **GB/T 2828.4-2008**《第4部分：声称质量水平的评定程序》（采标 ISO 2859-4:2002），含 LQR（极限质量比）与 DQL（声称质量水平）。
  - GB/T 2828.2 为**孤立批**的 LQ 检索抽样计划（待核实具体版本）。
- GB/T 2828.1 的检验水平（一般检验水平 I、II、III；特殊水平 S-1~S-4）与 AQL 共同决定样本量字码和抽样方案；正常/加严/放宽检验的转移规则用于动态控制。

> 提示：GB/T 2828 源自工业"逐批检验"，**用于食品监督抽检时须结合食品特性与法定限量**，不能简单套用"批合格"逻辑替代对不合格品（超标样品）的认定。

### 1.3 执法抽检 vs 风险监测抽样

| 维度 | 监督抽检（执法） | 风险监测 |
|---|---|---|
| 目的 | 发现并处置不合格食品、取证执法 | 掌握污染水平与趋势、为风险评估/标准提供数据 |
| 依据 | 《食品安全抽样检验管理办法》等（**令号/施行日期以官方发布为准**） | 《食品安全风险监测管理规定》（2010 年通过，据 CFSA）；CFSA 组织 |
| 抽样方式 | 按抽检计划/细则随机抽取，程序法定、证据链完整 | 分层随机，兼顾地域/时节/品类代表性 |
| 结果用途 | 合格/不合格判定、公示、处罚、召回 | 统计分布、暴露评估，不作个体处罚依据 |
| 样品 | 检样、复检备份样（异议复检用）、必要时留样 | 按监测方案，统一编号与质控 |

### 1.4 样品量与代表性

- 样品量应满足**检测方法最小取样量 + 平行/加标 + 复检备份**；微生物项目按 GB 4789 系列与 GB 29921 的采样方案（n、c、m、M）执行。
- 代表性取决于：抽样单元覆盖、随机性、运输保存条件、样品的均质化。对不均匀危害（如真菌毒素、异物），需增加份样并混合缩分。
- 二级/三级采样方案（n 个样品、c 个允许介于 m 与 M 之间）是微生物限量的标准表达方式。

### 1.5 采样与保存通用要求

- 使用洁净、惰性、密闭容器；微生物样品用**无菌**器具与容器，避免交叉污染。
- 快速冷却/冷藏（一般 0~4 ℃，冷冻品 ≤ −18 ℃）；避光、防吸湿、防挥发（如农药、亚硝酸盐、挥发性有机物）。
- 现场记录：品名、批号、生产日期、抽样基数、抽样人、地点、时间、封样状态、温控。
- 样品运输时限与保存期限应与检测项目匹配，并留存交接记录。

## 二、监测数据统计分析

### 2.1 基础指标

| 指标 | 计算 | 说明 |
|---|---|---|
| 检出率 | 检出数 / 检测总数 ×100% | 反映暴露普遍性；含低于 LOQ 的检出 |
| 超标率 | 超标数 / 检测总数 ×100% | 与**法规限量**比较后判定 |
| 均值 | 算术/几何均值 | 污染物偏态分布宜用几何均值或对数正态处理 |
| 分位数 | P50、P90、**P95、P99** | 关注高暴露尾部；用于暴露评估与风险分级 |
| 离散度 | 标准差、CV(RSD) | 评价批次稳定性 |
| 置信区间 | 均值的 95% CI；比率的 Wilson/Clopper-Pearson 区间 | 小样本比率不宜用正态近似 |

- **低于检出限（LOD）的数据处理**：常用 1/2 LOD 替换、或最大似然/稳健回归；须在报告中声明规则，不同规则影响均值与 P95。
- 比率置信区间：超标率低（<5%）时优先精确法（Clopper-Pearson）。

### 2.2 趋势与分布分析

- **时间趋势**：年度/季度超标率、均值；可用线性回归、Mann-Kendall 趋势检验；注意季节性（如夏季微生物）。
- **空间分布**：按省份/产区/门店做专题图与热点分析（Getis-Ord、核密度）。
- **回归分析**：Logistic 回归识别超标风险因素（品类、包装、储存温度、企业规模）；Poisson/负二项回归用于检出计数。
- **聚类/异常检测**：层次聚类、K-means 对地区/品类分组；Isolation Forest、时间序列异常检测用于**预警**。
- **预警阈值**：可设"均值 + k·SD"或 P95/P99 为警戒线，结合法规限量构建分级预警（绿/黄/红）。

### 2.3 风险表征衔接（与风险四步法）

- 暴露量 = 食品中浓度 × 消费量 / 体重；有阈值用 HQ = 暴露量 / ADI（或 TDI），HQ>1 需关注；无阈值致癌物用 MOE = BMDL / 暴露量，MOE 越小风险越高。
- 监测数据是暴露评估的输入；超标率是风险排序的初筛指标，但**不能替代**基于消费量的暴露评估。

## 三、检测方法与确证

### 3.1 常用方法分类

| 类别 | 典型技术 | 适用 |
|---|---|---|
| 色谱-质谱（确证） | LC-MS/MS、GC-MS/MS、HRMS（Q-TOF/Orbitrap） | 农残、兽残、真菌毒素、非法添加物 |
| 元素分析 | ICP-MS、ICP-OES、AAS、AFS | 重金属 Pb/Cd/Hg/As、微量元素 |
| 色谱（定量） | HPLC、GC、IC、GPC | 添加剂、维生素质、生物胺、有机酸 |
| 免疫分析（快筛） | ELISA、胶体金/荧光侧向层析 | 真菌毒素、兽残、过敏原现场快筛 |
| 微生物 | 传统培养计数、PCR/qPCR、LAMP、全基因组测序（溯源） | 沙门氏菌、单增李斯特菌、E. coli O157:H7、金葡菌 |
| 快速检测 | 便携光谱、传感器、试纸条 | 现场初筛，**阳性须用确证方法复测** |

> 执法判定以**标准方法/确证方法**为准；快检阳性只能作为线索，需按法定程序用确证方法复核。

### 3.2 方法性能参数

| 参数 | 含义 |
|---|---|
| 检出限 LOD | 能以规定置信度检出的最低浓度（常按信噪比 S/N=3 或空白 SD 的 3 倍估计） |
| 定量限 LOQ | 能准确定量的最低浓度（常 S/N=10；或空白 SD 的 10 倍） |
| 回收率 Recovery | 加标测定值 / 加标量 ×100%，评价准确度 |
| 精密度 Precision | 重复性/中间精密度，以 RSD 表示 |
| 线性范围/校正曲线 | 相关系数、权重、残差分布 |
| 专属性/选择性 | 共存物不干扰目标物 |
| 耐用性 Robustness | 小变动（柱温、pH、流速）不影响结果 |
| 测量不确定度 | 表征测定值分散性的非负参数，用于判定与限量比较 |

### 3.3 方法验证与确认

- **验证（validation）**：证实方法适用于预期用途，内容包括检出限、定量限、线性范围、专属性、准确度（回收率）、精密度、耐用性、系统适用性等；仪器须先完成安装确认（IQ）、运行确认（OQ）、性能确认（PQ）。
- **确认（verification）**：实验室引入标准方法时，证实本实验室能正确操作该方法，通常做准确度、精密度、LOQ 等关键指标。
- 相关规范：GB/T 27417《合格评定 化学分析方法确认和验证指南》、GB/T 27404《实验室质量控制规范 食品理化检测》（**版本以现行为准**）、GB/T 27025《检测和校准实验室能力的通用要求》（等同采用 ISO/IEC 17025:2017，**待核实最新版等同关系**）。

### 3.4 质控与不确定度

- 每批质控：空白、加标回收、标准物质/质控样（CRM）、平行样、能力验证/实验室间比对；用控制图监测漂移。
- 结果报告应给出：方法依据、检出限、不确定度、判定与限量的比较。
- 不确定度来源：取样、前处理、标准品纯度、称量/定容、仪器漂移、基质效应、随机误差。扩展不确定度常取包含因子 k=2（约 95% 置信）。
- 判定规则：当结果接近限量时，应结合**测量不确定度**评估"合规/超标"的稳健性，避免临界误判。

## 四、HACCP 七原则与十二步骤

HACCP（危害分析与关键控制点）是预防性食品安全控制体系：识别、评估并控制从原料到消费全过程的危害。国际基准为 Codex《食品卫生通则》（CXC 1-1969，含 HACCP 体系及其应用准则）；我国《食品安全法》第四十八条鼓励食品生产经营企业实施 HACCP 体系（据公开资料）。

### 4.1 七项原则

| 原则 | 内容 |
|---|---|
| 1 危害分析 | 识别生物、化学、物理危害，评估严重性与可能性，提出预防措施 |
| 2 确定关键控制点 CCP | 能防止、消除或降低危害至可接受水平的控制点 |
| 3 建立关键限值 CL | 每个 CCP 的可测量界限（如温度、时间、pH、水分活度、金属探测灵敏度） |
| 4 建立监控程序 | 明确监控对象、方法、频率、人员，确保 CCP 受控 |
| 5 建立纠偏措施 | CCP 失控时的处置（隔离、返工、降级、销毁）与原因纠正 |
| 6 建立验证程序 | 确认体系有效运行（审核、检测、复核记录） |
| 7 建立记录保持程序 | 完整、可追溯的记录与文件管理 |

### 4.2 十二个实施步骤

| 步骤 | 内容 |
|---|---|
| 1 | 组建 HACCP 小组（多学科：生产、质量、微生物、工程） |
| 2 | 描述产品（成分、工艺、包装、贮存、保质期） |
| 3 | 确定预期用途与消费者（是否高危人群） |
| 4 | 绘制生产流程图 |
| 5 | 现场确认流程图（走线核对） |
| 6 | 进行危害分析（原则 1） |
| 7 | 确定 CCP（原则 2，用决策树） |
| 8 | 建立关键限值（原则 3） |
| 9 | 建立监控程序（原则 4） |
| 10 | 建立纠偏措施（原则 5） |
| 11 | 建立验证程序（原则 6） |
| 12 | 建立记录保持程序（原则 7） |

## 五、CCP 判定决策树与常见工艺 CCP

### 5.1 Codex CCP 判定决策树（四问顺序）

对每个已识别的显著危害，依次提问：

1. **Q1**：本步骤是否有预防/控制该危害的措施？——否 → 非 CCP，但需考虑工艺或产品改造；是 → Q2。
2. **Q2**：本步骤能否将危害消除或降低到可接受水平？——是 → **CCP**；否 → Q3。
3. **Q3**：危害是否可能在此步骤后增加到不可接受水平？——否 → 非 CCP（保持前提方案）；是 → Q4。
4. **Q4**：后续步骤能否消除危害或将其降低到可接受水平？——是 → 非 CCP（后续步骤为 CCP）；否 → **CCP**。

> 决策树是工具而非唯一依据；判定结论须由 HACCP 小组结合科学证据作出并形成记录。

### 5.2 常见工艺 CCP 示例

| 工艺/步骤 | 典型监控参数 | 关联危害 | 备注 |
|---|---|---|---|
| 热杀菌/蒸煮 | 温度、时间（中心温度） | 致病菌（沙门氏菌、李斯特菌等） | 低酸罐头按 CXC 23-1979 等做热力杀菌 |
| 巴氏杀菌 | 温度-时间组合 | 病原菌、酶失活 | 乳品等 |
| 金属探测 | 灵敏度（Fe/非铁/不锈钢，按风险设定） | 物理危害（金属碎片） | 灵敏度与产品/包装匹配 |
| X 光异物检测 | 检出能力（玻璃、骨、石） | 物理危害 | 与金属探测互补 |
| 冷藏/冷链 | 温度（如冷藏 0~4 ℃，冷冻 ≤ −18 ℃） | 致病菌与腐败菌生长 | 冷链关键限值按产品设定 |
| 过滤/筛分 | 滤网/筛孔孔径 | 物理危害、虫体 | 定期检查完整性 |
| 酸化/低酸罐头 | pH（如 ≤ 4.6）、水分活度 | 肉毒梭菌等 | 酸性与酸化低酸食品 |
| 发酵 | pH、酸度、温度、时间 | 病原菌、生物胺 | 发酵剂与终点控制 |
| 干燥 | 水分活度 aw、含水率 | 微生物生长、毒素 | 与储藏安全相关 |
| 原料验收/毒素 | 真菌毒素、农残、兽残限值 | 化学危害 | 供应商管理与 COA |

> 具体限值（如金属探测灵敏度直径、杀菌 F0 值、冷藏温度）应经科学验证并由企业 HACCP 文件规定，**不可套用未经验证的通用数字**。

## 六、与 ISO 22000、GMP、SSOP、前提方案的关系

### 6.1 概念层级

| 体系 | 定位 | 与 HACCP 关系 |
|---|---|---|
| GMP（良好生产规范） | 厂房、设施、人员、卫生、过程的**通用强制/规范要求** | HACCP 的**基础**；GMP 不达标则 HACCP 空中楼阁 |
| SSOP（卫生标准操作程序） | 具体卫生操作（清洗消毒、人员卫生、虫害、水、交叉污染等） | HACCP 的支撑程序，聚焦卫生类前提条件 |
| PRP（前提方案） | ISO 22000 术语，涵盖 GMP/SSOP 等基础条件 | HACCP 的基础；含 PRP 与 OPRP |
| OPRP（操作性前提方案） | 用于控制非 CCP 的显著危害，需监控 | 介于 PRP 与 CCP 之间 |
| HACCP | 针对**显著危害**的关键控制点体系 | 建立在上述基础之上 |
| ISO 22000 | 可审核的食品安全管理体系标准（ISO 22000:2018），融合 HACCP 与 PRP/OPRP | 用 PDCA 与"危害分析+控制措施"组织 HACCP 原则 |
| ISO 22003-1:2022 | 食品安全管理体系审核与认证机构要求 | 认证依据 |

### 6.2 相互关系要点（据行业通行表述）

- **GMP + SSOP 是 HACCP 计划制定与实施的基础和前提**；没有有效 GMP/SSOP，HACCP 计划无法落地。
- GMP 偏"静态"规范、覆盖面广；HACCP 偏"动态"、抓住关键环节，二者相辅相成。
- 常见 SSOP 八大方面：水的安全；食品接触面清洁；防止交叉污染；手部清洁与卫生间设施；防止外来污染物；有毒化学物控制；员工健康；虫害控制。
- ISO 22000 用 OPRP 处理"不必设 CCP 但需控制"的显著危害，与 CCP 形成两级控制结构（CCP 由 HACCP 计划管理，OPRP 由操作性前提方案管理）。
- 我国相关：GB 14881《食品生产通用卫生规范》、GB 12693 乳制品 GMP、GB 17405 保健食品 GMP（**新版年份待核实**）；HACCP 认证依据《危害分析与关键控制点(HACCP)体系认证要求》等。

## 七、企业自检、不合格品处置与召回

### 7.1 企业自检与出厂检验

- 建立原料进厂、过程、成品出厂的检验制度；对照 GB 2760/2761/2762/2763/31650、GB 29921 等强制性标准判定。
- 自检能力不足时委托具备资质的检验机构；保留检验报告与原始记录。
- 定期开展内部审核、管理评审、供应商审核与追溯演练。

### 7.2 不合格品处置

| 情形 | 处置 |
|---|---|
| 采购/过程不合格 | 隔离、标识、评审；退货/换货/返工 |
| 成品不符合食品安全标准 | **不得出厂销售**；已出厂须召回 |
| 可返工 | 经风险评估与验证，返工后重新检验合格方可放行 |
| 不可返工 | 降级（限非食用用途）或无害化销毁，留存记录 |

### 7.3 召回与追溯

- 依据《食品召回管理办法》（原国家食品药品监督管理总局令**第12号，令号/施行日期以官方发布为准**），按危害严重程度分**一级、二级、三级**召回，级别越高启动与完成时限越短（**具体时限以现行法规原文为准**）。
- 召回流程：停止生产销售 → 通知经营者/消费者 → 召回并封存 → 无害化处理/销毁 → 向监管部门报告 → 记录与效果评估。
- 追溯：建立"从农田到餐桌"批次追溯，记录保存期限应符合法规（一般不少于产品保质期满后 6 个月，无明确保质期不少于 2 年，**以现行规定为准**）。
